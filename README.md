# Hour Time — site

Public home, support, and legal pages for the **Hour Time** iPhone app, served via GitHub Pages.

| Page | URL | Used for |
| --- | --- | --- |
| `index.html` | https://cafeasp.github.io/hour-time-site/ | Home page; currently also the App Store Connect **Support URL** (links to Support) |
| `support.html` | https://cafeasp.github.io/hour-time-site/support.html | Support and FAQ |
| `privacy.html` | https://cafeasp.github.io/hour-time-site/privacy.html | App Store Connect **Privacy Policy URL**, and the in-app paywall link |
| `terms.html` | https://cafeasp.github.io/hour-time-site/terms.html | In-app paywall link |

This repo is public only so GitHub Pages can serve it. The app source lives elsewhere and
is not published here.

`privacy.html` is the canonical copy. A duplicate is kept at `docs/legal/privacy-policy.html`
in the app repo; if you edit one, edit the other.

The home page follows Apple's App Store marketing guidelines: the badge in `images/` is
Apple's official black badge, downloaded unmodified from
[App Store Marketing Tools](https://toolbox.marketingtools.apple.com/app-store/); use it
once per page, and keep the Apple trademark line in the footer. Screenshots in `images/`
come from the app's fictional demo data, never real people.
