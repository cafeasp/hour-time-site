# Hour Time — site

Public support and legal pages for the **Hour Time** iOS app, served via GitHub Pages.

| Page | URL | Used for |
| --- | --- | --- |
| `index.html` | https://cafeasp.github.io/hour-time-site/ | App Store Connect **Support URL** |
| `privacy.html` | https://cafeasp.github.io/hour-time-site/privacy.html | App Store Connect **Privacy Policy URL**, and the in-app paywall link |
| `terms.html` | https://cafeasp.github.io/hour-time-site/terms.html | In-app paywall link |

This repo is public only so GitHub Pages can serve it. The app source lives elsewhere and
is not published here.

`privacy.html` is the canonical copy. A duplicate is kept at `docs/legal/privacy-policy.html`
in the app repo; if you edit one, edit the other.
